Entry for the [make.fun bounty "Sum up 20 November's world news in one image"](https://make.fun/bounty/news-image-20261120): a program (`main.py`, Python 3.13) that writes one 1024x1024 PNG summing up Friday 20 November 2026's world news to `/output/entry.png`. Deterministic, no network.

## The image

A newspaper front page, "THE WORLD TODAY", dated FRIDAY, 20 NOVEMBER 2026, built from the day's verified world news (see below).

## Build

Run `python3 main.py` — it copies the generated `entry.png` to `/output/entry.png`.
